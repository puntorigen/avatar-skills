# pdf-remix — reference

Full schemas, per-archetype content fields, palette semantics and troubleshooting.

---

## Pipeline data flow

```
reference.pdf
   │  analyze_pdf.py
   ▼
runs/<slug>/
   blueprint.json         ← the reusable MOLD (design system + pages + arc)
   blueprint.md           ← human-readable mold
   content_template.json  ← editable skeleton (author NEW content here)
   preview/page-NN.png    ← rendered reference pages

content.json  (authored by you from the template)
   │  generate_assets.py         │  build_pdf.py
   ▼                             ▼
assets/<id>.png               output.pdf
assets/assets_manifest.json
```

## blueprint.json (the mold)

```jsonc
{
  "source_pdf": "…/reference.pdf",
  "page_count": 28,
  "geometry": {"page_count":28,"w_pt":595,"h_pt":842,"format":"A4","orientation":"portrait"},
  "design_system": {
    "palette": {"ink","paper","accent","accent_dark","on_dark","muted"},   // #hex, pixel-derived
    "palette_semantics": {"ink":"use…","paper":"…","accent":"brand color use…", …},
    "fonts_detected": ["embedded font basenames…"],
    "typography": {"display_serif":"when/for what","brush_script":"…","signature_script":"…",
                   "handwritten":"…","body_sans":"…"},
    "type_scale": "approx size relationships",
    "emphasis_rules": {"key_claim":"…","self_talk":"…","accent_usage":"…","highlight_style":"…"},
    "motifs": ["recurring elements: hairlines, brand bars, symbolic objects, photo treatment"]
  },
  "layout_archetypes": [{"id":"section_opener","count":7}, …],   // observed counts
  "narrative_arc": {
    "type":"…", "voice":"…", "beats":["…"],
    "section_unit": {"pages_per_item":3, "sub_pages":["opener","what_is","split_grid"]},
    "cta": {"type":"…","pattern":"…"}
  },
  "replication_notes": "3-5 rules to match/beat the original",
  "pages": [ {
     "n":1, "archetype":"cover", "background":"fullbleed_photo",
     "imagery":[{"role":"author_portrait","subject":"person","treatment":"b&w cinematic",
                 "camera":"medium","position":"right","description":"…"}],
     "text_blocks":[{"role":"title","font_style":"serif_display","case":"title","color":"ink",
                     "align":"left","emphasis":"none","size":"xl","text":"verbatim"}],
     "highlight_words":["…"], "narration":"…", "layout_notes":"…",
     "dominant_colors":["#…"], "preview":"preview/page-01.png"
  }, … ]
}
```

The **archetype** vocabulary (also the set of CSS layouts in `build_pdf.py`):
`cover, quote_dark, manifesto_text, statement_object, section_opener, what_is,
split_grid, bridge, cta_closing, freeform`.

## content.json (what you author + what build_pdf.py consumes)

```jsonc
{
  "brand": {
    "name": "Author Name",
    "handle": "@handle",
    "author_byline": "Por Author Name",
    "channel_url": "instagram.com/handle",
    "reference_images": ["/abs/photo1.jpg", "/abs/photo2.jpg"],  // identity for author_portrait
    "palette_override": {"accent":"#c4121a", …}                   // optional, overrides blueprint
  },
  "meta": {"title":"…","subtitle":"…","topic":"…","language":"es"},
  "pages": [ /* one object per page, keyed by archetype (see below) */ ]
}
```

### Inline markup (usable in any text field)

| Markup | Renders | Use for |
|---|---|---|
| `**text**` | **bold** | key claims |
| `*text*` | *italic* | self-talk, quotes, book-titles |
| `==text==` | accent color | highlighted words (no box — color swap) |
| blank line | new paragraph | body fields only |

### Assets on a page

Every page may carry an `assets` array. Each asset is generated by
`generate_assets.py` and referenced by the layout fields via its `id`.

```jsonc
{"id":"p05_photo",
 "kind":"author_portrait|emotive_photo|symbolic_bg|product_mockup|texture|hero_photo",
 "aspect":"2:3",              // asset-generator ratio; 2:3 full-bleed, 3:4 panels/cells
 "prompt":"what to depict for the NEW topic",
 "treatment":"black and white cinematic",       // optional; else the mold's directive applies
 "composition":"subject on the right, empty upper-left for a title",  // author_portrait only
 "screen":"what the tablet displays",           // product_mockup only
 "transparent": false}
```

`kind` → (asset-generator style, default aspect, uses references):
`author_portrait`→photo/3:4/**uses brand.reference_images**, `emotive_photo`→photo/3:4,
`hero_photo`→photo/2:3, `symbolic_bg`→photo/2:3, `product_mockup`→photo/3:4,
`texture`→background/2:3.

### Per-archetype content fields

Reference an asset by putting its `id` (or a file path) in the field named below.

| Archetype | Fields | Asset fields |
|---|---|---|
| `cover` | `title`, `subtitle`, `callout` (white body block), `byline`, `brand_bar` | `portrait` |
| `quote_dark` | `quote` (serif italic), `brush` (accent script line), `tail` (serif italic) | — |
| `manifesto_text` | `head_display`, `head_brush`, `body` | `photo` (optional) |
| `statement_object` | `statement` (upper serif), `accent_line` (accent), `handwritten` | `bg` |
| `section_opener` | `side` (`left`/`right`), `kicker` (script "Item #N"), `name` (serif), `quote` (handwritten) | `photo` |
| `what_is` | `variant` (`fullbleed_dark`/`photo_top`), `title` (accent), `body` | `photo` |
| `split_grid` | `cells`: 4× `{type:"text", section_title, body}` or `{type:"photo", asset:"<id>"}` | in cells |
| `bridge` | `head_brush`, `head_display`, `body`, `sub` (secondary serif headline), `body2` | — |
| `cta_closing` | `lead`, `headline`, `body`, `button`, `foot` | `mock` |
| `freeform` | any of `title`, `section_title`, `quote`, `body` | `assets[]` |

`split_grid` renders its 4 cells in a 2×2 grid in array order (row-major:
top-left, top-right, bottom-left, bottom-right). Mirror the mold by alternating
text/photo (e.g. `text, photo, photo, text`).

## Typographic roles → bundled fonts

| Role (blueprint) | CSS var | Bundled font | Character |
|---|---|---|---|
| `display_serif` | `--f-display` | Playfair Display | high-contrast Didone titles |
| `body_sans` | `--f-body` | Inter | neutral grotesque body |
| `brush_script` | `--f-brush` | Kaushan Script | bold emotive accent script |
| `signature_script` | `--f-sign` | Great Vibes | elegant signature/byline |
| `hand_marker` | `--f-hand` | Caveat | casual inner-voice handwriting |

Swap any role by editing `fonts/fonts.json` (`roles` map) and dropping the TTF in
`fonts/`. Missing files degrade gracefully to CSS generics.

## Palette semantics

| Slot | Meaning |
|---|---|
| `ink` | darkest — headlines on light pages, body text, solid-dark page background |
| `paper` | lightest — base background of reading/analysis pages |
| `accent` | the brand color — chapter numbers, section titles, CTA, emotional hits **only** |
| `accent_dark` | darker accent — brand bar / inverted bands |
| `on_dark` | text over dark photos / dark pages (usually `#ffffff`) |
| `muted` | secondary text, eyebrows, captions |

`pick_palette()` derives these from pixels (darkest=ink, lightest=paper,
most-saturated mid-tone=accent). Override any slot via `brand.palette_override`.

## Command cheat-sheet

Paths below use the installed layout (`.cursor/skills/pdf-remix/...`); from inside
the repo skill folder the `scripts/...` relative form works too.

```bash
# analyze (add --no-vision for geometry/palette only; --max-pages N to sample)
python3 .cursor/skills/pdf-remix/scripts/analyze_pdf.py "ref.pdf" --out-dir runs/x [--dpi 120]

# assets (preview prompts / regenerate a subset)
python3 .cursor/skills/pdf-remix/scripts/generate_assets.py --content runs/x/content.json --blueprint runs/x/blueprint.json --dry-run
python3 .cursor/skills/pdf-remix/scripts/generate_assets.py --content runs/x/content.json --only p01_portrait,p05_photo --force

# build (fast HTML iteration, then full PDF)
python3 .cursor/skills/pdf-remix/scripts/build_pdf.py --content runs/x/content.json --blueprint runs/x/blueprint.json --html-only
python3 .cursor/skills/pdf-remix/scripts/build_pdf.py --content runs/x/content.json --blueprint runs/x/blueprint.json -o runs/x/output.pdf
```

## Troubleshooting

- **Vision analysis is generic / empty** — ensure the Gemini key is set in
  `asset-generator/config.json`. Without it, `analyze_pdf.py` still emits
  geometry + palette + per-page previews but archetypes fall back to `freeform`.
- **Fonts look like default serif/sans** — run `setup_fonts.py`; check
  `setup_fonts.py --check`. Chromium loads them via `file://` `@font-face`.
- **A photo shows a placeholder box** — the asset id in the layout field doesn't
  match a file in `assets/`. Confirm the `id`, then `generate_assets.py --only <id>`.
- **Text sits on a busy photo and is hard to read** — `what_is fullbleed_dark`
  and `cover` already apply gradient scrims; for other pages prefer `photo_top`
  or move the copy to a solid panel.
- **PDF render fails** — `pip3 install playwright && python3 -m playwright install chromium`.
- **Cover portrait isn't the right person** — pass 1–3 clear face photos in
  `brand.reference_images`; keep `kind:"author_portrait"`; describe only pose +
  composition (identity is preserved from the references).
- **Accent color too dark/muted** — set `brand.palette_override.accent` to the
  exact brand hex; pixel extraction can pick a darker variant (e.g. a brand bar).
